# Беседки Казани — сайт besedki-kazani.ru

## 1. Фотографии
Ваши 9 фото уже подключены (сжаты до 1600–1920 px) и лежат в `images/`: `hero.jpg` (первый экран) и `work-1.jpg … work-9.jpg` (галерея, каталог и блок «О производстве»).
Чтобы заменить фото — положите файл с тем же именем в `images/`. Какая карточка каталога какое фото использует, задаётся полем `photo` в списке `MODELS` в index.html.

## 2. Данные (index.html, блок `CFG` и `MODELS` в начале скрипта)
- `phone`, `whatsapp`, `telegram` — контакты (телефон и WhatsApp уже указаны; Telegram — mrsadmen_kzn; также заданы `vk`).
- `MODELS` — названия, размеры, материалы, цены моделей (цену можно оставить `""`).
- `works` — число фото в «Наших работах».
- В разделах «О производстве» и «Этапы» есть пометки ✎ — замените на проверенные факты и удалите.

## 3. Бесплатная публикация (GitHub Pages)
1. Зарегистрируйтесь на github.com → New repository (Public), например `besedki-kazani`.
2. Загрузите все файлы из этой папки (Add file → Upload files), включая `images/` и `CNAME`.
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. В Pages в поле Custom domain впишите `besedki-kazani.ru`.

## 4. DNS в Timeweb
Панель Timeweb → Домены → besedki-kazani.ru → DNS-записи. Удалите старые A-записи и добавьте:
- A, `@` → 185.199.108.153
- A, `@` → 185.199.109.153
- A, `@` → 185.199.110.153
- A, `@` → 185.199.111.153
- CNAME, `www` → `ваш-логин.github.io`

Обновление DNS занимает от 15 минут до суток.

## 5. SSL (HTTPS)
Когда DNS заработает, в GitHub Settings → Pages включите **Enforce HTTPS** — сертификат выдаётся бесплатно автоматически.

## 6. После запуска
- Проверьте на телефоне: кнопки, форма, просмотр фото.
- Добавьте сайт в Яндекс Вебмастер и Google Search Console (sitemap: https://besedki-kazani.ru/sitemap.xml).

Логотип «СадМен» сделан из вашего файла в белом варианте с прозрачным фоном: `images/logo-icon.png` (значок), `logo-word.png` (надпись), `logo-white.png` (полный, для подвала), `favicon.png`. Цвет шапки #797d5c взят с hozblok-premium.ru; цвета меняются в начале CSS (блок `:root`).
